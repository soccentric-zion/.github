# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting: open the repository, go to the
**Security** tab, and choose **Report a vulnerability**. We will acknowledge
your report, keep you updated, and credit you when the fix is released unless
you prefer to stay anonymous.

## Supported versions

Security fixes go to the `develop` branch and the latest tagged release.
