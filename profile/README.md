# Zion

Open-source embedded Linux platform for **AMD Xilinx Zynq**, from [SoCcentric](https://github.com/Soccentric).
MIT licensed.

| Repository | Purpose |
|---|---|
| [Zion-OS](https://github.com/soccentric-zion/Zion-OS) | Yocto/kas image build |
| [meta-zion](https://github.com/soccentric-zion/meta-zion) | Yocto layer for the board |
| [Zion-HAL](https://github.com/soccentric-zion/Zion-HAL) | Hardware abstraction layer (C++17) |
| [Zion-Client](https://github.com/soccentric-zion/Zion-Client) | gRPC client (C++17) |
| [Zion-Server](https://github.com/soccentric-zion/Zion-Server) | Test server (Drogon, C++) |
| [Zion-Configuration](https://github.com/soccentric-zion/Zion-Configuration) | WebConfig on-device configuration |
| [Zion-Dashboard](https://github.com/soccentric-zion/Zion-Dashboard) | HTML5 dashboard |
| [Zion-PySDK](https://github.com/soccentric-zion/Zion-PySDK) | Python SDK |
| [Zion-Instrumentation](https://github.com/soccentric-zion/Zion-Instrumentation) | On-device management and observability |
| [Zion-HQ](https://github.com/soccentric-zion/Zion-HQ) | Fleet management |
| [Zion-Hardware](https://github.com/soccentric-zion/Zion-Hardware) | Hardware documentation |

Contributions go to the `develop` branch. See the shared [contributing guide](https://github.com/soccentric-zion/.github/blob/main/CONTRIBUTING.md).
